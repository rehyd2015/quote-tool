📖 How to Use This Tool

First Time Setup (5 minutes)

  1. Settings tab → Fill RUDRA ELECTRICALS details (company name, address, GSTIN, PAN, bank) → Upload logo → Save
  2. Price List tab → Add your products with MRP + default discount. You can add more later as needed.
  3. For bulk import, use CSV with columns: Name, Keywords, Brand, Unit, MRP, Discount, GST, Category, HSN

✨ Auto Customer Detect

Just paste the whole email in requirement box. The tool will auto-detect customer name from these patterns:
• To: CompanyName
• Dear CompanyName
• First line if it looks like a company name
Customer name field will auto-fill. You can edit if wrong.

✏️ Edit Saved Quotes

Go to History tab → click Edit on any quote → make changes → click Update Quote. Original quote will be replaced with updated version. Quote number stays the same.

Quote Print Format (Rudra Electricals Style)

  • Header: QUOTATION title centered, company name + address + GSTIN + PAN
  • Buyer Name & Address block (left) and Delivery at block (right)
  • Quotation No. / Date, Supplier Ref, Payment, Delivery Terms
  • Table columns: S.No, Material Description (with Brand), GST%, Qty, UOM, MRP/List Price, Disc%, Rate After Disc, Amount After Disc, Amount Incl. GST
  • Grand Totals row
  • Total Value in words (Indian Rupees... Only)
  • Remarks + Company's Bank Details
  • "for RUDRA ELECTRICALS / Authorised Signatory"
  • Footer: "This is a Computer Generated Document"
